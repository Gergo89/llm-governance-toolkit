The RE=E=I Governance Theorem

Core Theorem

For a system at emergence level L, external governance requires that the regulator's model of the system be at level ≥ L.

INERT–PATTERNED
Rule auditing, output sampling, black-box testing. Regulator model can be simpler than the system.
EQUIVALENT
Requires interpretability tools — probes, activation patching, concept vectors. Cross-domain analogy checking is necessary.
IDENTIFIED
Regulator must model the system's self-model. Governance that ignores the self-model will be systematically gamed.
CLOSED
External governance is categorically impossible without co-constitution. Alignment must be constitutive (baked in), not regulative (imposed from outside).
